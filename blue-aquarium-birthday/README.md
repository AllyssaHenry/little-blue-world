# Little Blue World 💙 — Birthday Aquarium

A small, responsive interactive birthday website with a blue pixel-aquarium-inspired look.

## Included
- Animated underwater scene
- Clickable fish that reveal your couple photos
- Jellyfish, pearl, and treasure chest messages
- Discovery progress bar and final birthday letter
- Mobile-friendly layout

## Add your photos
1. Open the `photos` folder.
2. Put your first couple photo in it and name it `us-01.jpg`.
3. Put your second couple photo in it and name it `us-02.jpg`.
4. If your images are PNG, update the filenames in `script.js` to end in `.png`.

The photo files are intentionally not included; add your own private photos.

## Personalise the messages
Open `script.js` and edit the text in `FISH_MEMORIES` and `SECRET_MESSAGES`, plus the final birthday message in `showFinalBirthdayMessage()`.

## Preview locally
Double-click `index.html` to open it in a browser.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `photos` folder with your images.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish your website. The URL will appear in the Pages settings.

Tip: only upload photos you're comfortable sharing through a public website. For a private birthday surprise, consider keeping the repository private and check GitHub Pages availability/settings for your account.
